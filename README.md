Student Study Assistant 

About the Project

Student Study Assistant is a beginner-friendly Python command-line application designed to help students organize their study tasks, test their knowledge, and track their learning progress.

The project uses JSON file storage to save tasks even after the program is closed.

Features

- Add new study tasks
- View all study tasks
- Take subject-wise quizzes (Python, SQL and DSA)
- Mark tasks as completed
- View study progress in percentage
- Save and load tasks using JSON
- Simple menu-driven interface

Technologies Used

- Python
- JSON
- PyCharm

Project Structure

StudentStudyAssistant/

How to Run

1. Install Python 3.
2. Download or clone this project.
3. Open the project folder in PyCharm or a terminal.
4. Run the following command:

python main.py

No additional Python libraries are required.

Main Menu

===== STUDENT STUDY ASSISTANT =====
1. Add Study Task
2. View Tasks
3. Take Quiz
4. Complete Task
5. View Progress
6. Exit

JSON Storage

Study tasks are stored in "tasks.json".

The application automatically updates the file whenever a task is added or marked as completed.
